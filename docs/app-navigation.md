# AV Tools navigation — Frappe v16.50+

The app Desktop entry opens `/desk/av-tools`. The seven Dock entries open their module Sidebars, with Home first. AV Tools Home links to Accounting, Stock and Manufacturing, People and Payroll, Administration, and each specialist module's landing workspace. Each business landing groups Transactions, Masters, Reports, and Settings where the app ships relevant targets. The Stock and Manufacturing landing also links the existing Manufacturing BOM Variance dashboard and its cards/charts.

Validated against Frappe `version-16` commit `6b450a166e076dd842e4db7ea0843f62881e62ac`. Run `python scripts/check_navigation.py` to check links, child-table exclusions, reports, workspace blocks, Dock coverage and the legacy copy.

## Access

Ordinary desk users can open the public home and business landings. Frappe filters document, page, report and dashboard links using underlying permissions; navigation grants no rights. Accounts users can reach reconciliation, HR users piecework and payroll, and stock users Special Closing Balance and variance reports. Many existing transaction DocTypes remain System Manager-only. Administration, AI and Google Chat workspaces require System Manager. Managers see only targets their existing roles permit. OTP Register retains its Accounts Manager/Sales Manager access.

The shared `Sales` module is not given an AV Tools Sidebar, Dock entry or code-only designation: ERPNext also uses that module. Its customer-statement Page and settings are linked from AV Tools Accounting. `Trade In` has no independent records and maps to Av Tools via `code_only_modules`.

## Installation and review

Merge into `version-16-hotfix`, update the app and run `bench --site <site> migrate` on Frappe v16.50+. Reload Desk and open AV Tools from Apps. Existing site/user Dock arrangements can hide newly shipped entries; a Workspace Manager can enable them in Manage Dock. No patches or fixture synchronization reset those arrangements.

These files were authored against upstream Frappe `version-16` schemas and shipped examples, not exported from a running site. Check migration and route opening with an Accounts User, HR User, Stock User, and System Manager before production. Check desktop logo, single-document forms, report routing, dashboard access and narrow-screen readability. No live bench is available in this workspace.

The existing `AV Tools` workspace and `Av Tools` sidebar IDs remain unchanged. The legacy top-level Workspace file is retained with identical content; the module path is the authoritative standard export. Child-table links were removed; missing operational/report links are now grouped in the appropriate business landing. No customer permissions or feature controllers were changed.

Rollback: revert the navigation commit, migrate, and reload Desk. Existing custom arrangements remain separate. New standard records are subject to Frappe's normal orphan cleanup; no custom records should be deleted manually.
